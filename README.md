# SNITCH AI Studio — approved presentation

Shruti’s approved narrated presentation, preserved for browser sharing and offline use.

- Public presentation (after Pages is enabled): https://smokingace0218.github.io/snitch-ai-studio-pitch/
- Original offline package: [download the approved release](https://github.com/smokingace0218/snitch-ai-studio-pitch/releases/download/approved-final/SNITCH-Pitch-Offline.zip).

Click **Start presentation**. Press **F** for fullscreen. The **More info** switch pauses narration; **Continue presentation** resumes it. Full-film playback is optional.

## What is preserved

All eight ideas, original narration/cues, diagrams, five selected original films, ending, source-linked technical research and detail view. No alternative narrative or generated experimental graphics are included.

GitHub serves the selected MP4s directly; the presentation no longer needs the former host’s ZIP-media loader. The approved offline ZIP is attached as a Release asset without modification.

## Local use

Open `index.html` in Chrome, or run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000`. No build or package installation is required.

## Deployment

A `.nojekyll` file keeps this as a plain static site. GitHub Pages should publish the root of `main`. No API keys or server process are required to play the presentation. Third-party documentation links require internet; the presentation’s own media are local or served from this repository.
